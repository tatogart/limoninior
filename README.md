# 🍋 Limoninior

Мессенджер в духе Telegram: юзернеймы, личные чаты, группы, фото, тёмная тема.
Работает в браузере и **устанавливается как приложение** (PWA) на ПК, Android и iPhone.

## Что умеет

- **Вход по @юзернейму и паролю** (регистрация прямо на сайте) или **через Google**
- **Стикеры**: набор «Лимончик» и «Живые эмодзи», панель эмодзи с недавними
- **Подарки** за внутреннюю валюту 🍋 «лимоны» (ежедневный бонус), подарки видны в профиле
- **Галочки** подтверждённых аккаунтов (выдаёт админ)
- **Автообновление**: сервер сам подтягивает новые версии с GitHub каждые 2 минуты
- **Поиск людей** по `@юзернейму` или имени, ссылки на профиль вида `https://ваш-домен/@username`
- **Личные чаты**, **группы** (создание, добавление/удаление участников, смена названия и аватарки), **Избранное**
- Сообщения в реальном времени: **«печатает…»**, **онлайн / был(а) недавно**, **✓ / ✓✓ прочитано**, счётчики непрочитанных
- **Ответ**, **редактирование** (в т.ч. стрелкой ↑), **удаление у всех**, копирование
- **Фото**: кнопка, вставка из буфера, перетаскивание. Перед отправкой фото сжимаются, из них **удаляются EXIF и геолокация**
- Аватарки, «о себе», крупные эмодзи, ссылки, разделители по дням, просмотрщик фото
- **Светлая / тёмная тема** + 6 цветов акцента, уведомления в браузере
- **Активные сеансы** — видно, где выполнен вход, можно завершить
- Адаптив: на ПК — две колонки, на телефоне — экраны со свайп-анимацией и кнопкой «назад»
- **Админка только для вас** (см. ниже)

## Безопасность

- Вход только через Google, токен проверяется на сервере (подпись, `audience`, подтверждённый email)
- Сессии: случайный 256-битный токен в cookie `__Host-sid` (`HttpOnly`, `Secure`, `SameSite=Lax`), в базе хранится только SHA-256 хеш
- Защита от CSRF (проверка `Origin`) и от перехвата WebSocket с чужих сайтов
- Строгий **CSP**, HSTS, `X-Frame-Options`, `nosniff`, отключённые camera/mic/geo
- Лимиты частоты запросов на вход, отправку, загрузку и поиск
- Загрузки: только изображения, тип определяется по содержимому файла, случайные имена, приватная раздача (фото из чата видят только его участники)
- Весь пользовательский текст выводится через `textContent` — XSS через сообщения невозможен
- systemd-сервис запускается от отдельного пользователя с жёсткой песочницей

### Админка — как она защищена

Админка открывается по адресу `/admin`, но **только если выполнены все условия**:

1. Вы вошли через Google с email из `ADMIN_EMAILS`.
2. (Необязательно) ваш IP есть в `ADMIN_IPS`.
3. Вы ввели **6-значный код из приложения-аутентификатора** (Google Authenticator, Яндекс Ключ, Aegis…). Код одноразовый — повторно его использовать нельзя; попыток не больше 5 за 15 минут.
4. Разблокировка действует 15 минут и только на этом устройстве.

Всем остальным сервер отвечает `404` — снаружи не видно даже, что админка существует.
Если `ADMIN_EMAILS` или `ADMIN_TOTP_SECRET` не заданы — админка выключена полностью.
Все входы, неудачные коды, попытки доступа и действия админа пишутся в **журнал безопасности**.

В админке: статистика, состояние сервера и кнопка **«Обновить сейчас»**, рассылка всем от официального аккаунта, список пользователей с поиском, **галочки**, **начисление лимонов**, **бан / разбан**, **завершение всех сеансов**, **сброс юзернейма**, журнал безопасности.

Админ с входом по паролю (без Google): впишите его юзернейм в `deploy/admin-usernames.txt` — автообновление само добавит его в `ADMIN_USERNAMES`.
Читать чужую переписку админка не умеет — так задумано.

## Установка на сервер (Ubuntu 22.04 / 24.04, в т.ч. в РФ)

Нужно: VPS с публичным IP и домен (или поддомен), A-запись которого указывает на сервер.

### 1. Google Client ID

1. Откройте <https://console.cloud.google.com/> → создайте проект.
2. **APIs & Services → OAuth consent screen**: тип *External*, заполните название и email, опубликуйте (*Publish app*).
3. **APIs & Services → Credentials → Create credentials → OAuth client ID**:
   - Application type: **Web application**
   - Authorized JavaScript origins: `https://ваш-домен` (для локальной разработки можно добавить `http://localhost:3000`)
   - Redirect URI не нужен.
4. Скопируйте **Client ID** (вида `123…-abc.apps.googleusercontent.com`).

### 2. Установка одной командой

```bash
git clone <этот-репозиторий> limoninior && cd limoninior
sudo bash deploy/install.sh chat.ваш-домен.ru ваш@gmail.com
```

Скрипт поставит Node.js 22 и Caddy (автоматический HTTPS от Let's Encrypt), создаст системного пользователя, сервис systemd, настроит файрвол и **один раз покажет ключ для админки** — сразу добавьте его в приложение-аутентификатор.

Затем впишите Client ID и перезапустите:

```bash
sudo nano /opt/limoninior/.env        # GOOGLE_CLIENT_ID=...
sudo systemctl restart limoninior
```

Готово — откройте `https://chat.ваш-домен.ru`.

**Обновление:** происходит само — таймер `limoninior-update.timer` раз в 2 минуты проверяет GitHub и, если есть новая версия, переустанавливает её (данные и `.env` не трогаются). Вручную: кнопка «Обновить сейчас» в админке или `sudo bash deploy/install.sh`. Лог: `/var/log/limoninior-update.log`.

**Логи:** `journalctl -u limoninior -f`

**Бэкап:** всё хранится в `/opt/limoninior/data` (база SQLite + фото):

```bash
sudo apt install sqlite3
sudo sqlite3 /opt/limoninior/data/limoninior.db ".backup /root/limoninior-$(date +%F).db"
sudo tar czf /root/limoninior-media-$(date +%F).tgz -C /opt/limoninior/data media
```

### Вариант через Docker

```bash
cp .env.example .env && nano .env              # заполните APP_ORIGIN, GOOGLE_CLIENT_ID, ADMIN_*
npm run admin:totp -- ваш@gmail.com            # или: docker compose run --rm app node scripts/admin-totp.js
sed -i 's/chat.example.ru/chat.ваш-домен.ru/' deploy/Caddyfile.docker
mkdir -p data && sudo chown 1000:1000 data
docker compose up -d --build
```

> Если Docker Hub недоступен с вашего сервера, используйте установку через `install.sh` — она не зависит от Docker.

## Установка «как приложение»

- **ПК (Chrome / Edge / Яндекс Браузер):** значок установки в адресной строке или «Меню → Установить Limoninior». Также пункт «Установить приложение» в боковом меню мессенджера.
- **Android (Chrome):** «⋮ → Установить приложение / Добавить на главный экран».
- **iPhone / iPad (Safari):** «Поделиться → На экран Домой».

## Локальная разработка

```bash
npm install
npm run dev          # http://localhost:3000, включён вход без Google (DEV_LOGIN=1)
```

Dev-вход работает **только** когда `NODE_ENV` не `production` и `DEV_LOGIN=1`.

## Стек

Node.js 22 (встроенный `node:sqlite`), Express 5, Socket.IO, google-auth-library, helmet.
Фронтенд — чистый JS без сборки, PWA с service worker.

```
server/   index.js (HTTP, CSP), api.js (REST), realtime.js (Socket.IO), auth.js (Google, сессии, CSRF),
          admin.js (админка + TOTP), media.js (загрузки), db.js (схема SQLite)
public/   index.html, js/app.js (мессенджер), js/admin.js, css/, sw.js, manifest, icons/
deploy/   install.sh, limoninior.service, Caddyfile
```
