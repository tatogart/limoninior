# 🍋 Limochat

Мессенджер в духе Telegram: юзернеймы, личные чаты, группы, фото, тёмная тема.
Работает в браузере и **устанавливается как приложение** (PWA) на ПК, Android и iPhone.

## Что умеет

- **Вход по @юзернейму и паролю** (регистрация прямо на сайте) или **через Google**
- **Стикеры**: набор «Лимончик» и «Живые эмодзи», панель эмодзи с недавними
- **Подарки** за внутреннюю валюту 🍋 «лимоны» (зарабатываются в мини-играх), подарки видны в профиле
- **Галочки** подтверждённых аккаунтов (выдаёт админ)
- **Каналы**: публичная ссылка `/@имя`, описание, аватар, подписчики, уникальные просмотры постов, предпросмотр до подписки, каталог популярных каналов, поиск
- **Приватные каналы**: не видны в поиске, вступление только по ссылке-приглашению `/join/…`, ссылку можно сбросить
- **Верификация каналов**: владелец подаёт заявку, админ одобряет или отклоняет, ответ приходит от официального аккаунта
- **Реакции** на сообщения и посты, **отключение уведомлений** для любого чата
- **Комментарии к постам** в каналах
- **Звонки** голосовые и видео (WebRTC, шифрование; на сервер автоматически ставится TURN-сервер coturn для работы через NAT)
- **Групповые звонки** (до 8 человек, голос и видео) в группах и **по ссылке** `/call/…`: плашка «идёт звонок» в чате, видно, кто говорит, можно свернуть звонок и переписываться
- **Прямые эфиры в каналах**: владелец и админы ведут видео/аудиоэфир (можно показывать экран), подписчики смотрят и шлют летающие реакции, до 50 зрителей
- **Сообщества (как серверы в Discord)**: «Создать… → Сообщество» — внутри текстовые чаты, каналы объявлений (пишут только админы) и голосовые комнаты; одна ссылка-приглашение `/community/…`, роли владелец / админ / участник, исключение и запрет входа
- **Огоньки 🔥 как в TikTok** — один предлагает растить огонёк, второй принимает; дальше пишите друг другу каждый день — огонёк растёт, вечером ⏳ напоминает, на круглых датах салют; погасший можно вернуть за 🍋 50 — 2 раза в месяц, огонёк можно погасить в меню чата
- **Мини-игры** вместо ежедневного бонуса: «Ловец лимонов», «Лимонные пары», «Реакция» — награда в лимонах (до 60 в день, с подпиской ×2/×3/×5), таблицы рекордов; в чате — 🎲 🎯 🏀 ⚽ 🎳, результат выбирает сервер
- **Роли и значки** за игру в лаунчере: «Неутомимый», «Легенда», «Ветеран» (роли — видны рядом с именем), «Коллекционер», «Исследователь» (значки — в профиле). Выдаёт админ вручную: «Админка → Роли и значки» → найти человека → отметить награды. Там же видно, у кого какая награда, можно забрать и добавить новые
- **Темы оформления**: 26 готовых тем (светлые и тёмные: Космос, Неон, Матрица, Сакура, Новый год…) и своя тема — цвета, обои, форма сообщений, шрифт и анимированный эффект (снег, сердечки, звёзды, лимоны…). Тему можно отправить в чат карточкой — собеседник включит её одним нажатием — или поделиться кодом
- **Профиль 2.0**: обложка (фото или свой градиент) с эффектом, эмодзи-статус рядом с именем везде, настроение, трек профиля (своя песня), город, день рождения (в этот день — 🎂 у имени), до 4 ссылок, интересы-теги, счётчик просмотров профиля за неделю
- **Кружки** — видеосообщения до 60 секунд с фронтальной или основной камеры; в чате крутятся без звука, по нажатию играют со звуком
- **Конструктор ботов без кода**: шаблоны (приветствие, вопрос-ответ, магазин, развлечения, автоответчик), бот отвечает сразу; в конструкторе — приветствие, команды, ответы на слова, кнопки (ответ или ссылка), «если не понял», переменные {first}, {date}, {random:…}. Для программистов по-прежнему есть Bot API
- **Игры на лимоны** между людьми прямо в чате: кости, камень-ножницы-бумага, монетка, крестики-нолики. Ставка держится сервером, победитель забирает банк, ничья/отмена/отказ возвращают лимоны, реванш в одно нажатие
- **Анонимные послания**: в профиле карточка «Напиши анонимно»; получатель не видит автора, может ответить (автор увидит ответ), удалить, заблокировать анонима или пожаловаться — модераторы видят настоящего автора
- **Капсулы времени** — письмо в будущее: в чате висит запечатанный конверт с обратным отсчётом и открывается у всех в назначенный момент (даже автор не видит текст раньше)
- **Напоминания о любом сообщении** — «Напомнить…» в меню сообщения: в нужное время оно вернётся в «Избранное» со ссылкой и придёт уведомление
- **Колесо решений** — варианты на колесе, результат честно выбирает сервер, все видят одно и то же вращение
- **Жалобы** на сообщения, людей, каналы и сообщества
- **Свои стикеры**: наборы из своих картинок (PNG/WebP/JPEG/GIF, до 120 в наборе), делятся ссылкой `/addstickers/…`; нажмите на чужой стикер, чтобы добавить его набор
- **Боты как в Telegram**: «Создать… → Боты» — бот, токен и HTTP API `/bot<токен>/<метод>` (getUpdates, sendMessage, кнопки под сообщениями, команды «/»); пример программы — в «Как подключить»
- **Демонстрация экрана** в обычных и групповых звонках (показывать — с компьютера, смотреть — с любого устройства)
- **Push-уведомления** о сообщениях и звонках, даже когда приложение закрыто (ключи VAPID создаются автоматически)
- **Файлы любого типа** (до 25 МБ, с подпиской — до 200 МБ); опасные (.exe, .apk, .bat…) помечаются, при скачивании — предупреждение
- **Безопасные ссылки**: подтверждение перехода, подозрительные (фишинг, подделки, IP, сокращатели) подсвечиваются красным
- **Liquid Glass** — стиль «жидкое стекло» (по умолчанию) или классический, обои чата, размер текста
- **Свои рингтоны и звуки уведомлений** (встроенные мелодии или свой аудиофайл), громкость, вибрация
- **В звонке**: выключение динамика и микрофона, выбор устройства вывода на ПК
- **Настройки уведомлений** по типам чатов, текст в пушах; **приватность**: кто видит время входа и кто может звонить
- **Профили** с обложкой и цветом, кнопками действий, подарками и общими фото
- **Подписки** Plus / Premium / Max: «Купить» открывает чат с продавцом, подписку выдаёт админ
- **Автообновление**: сервер сам подтягивает новые версии с GitHub каждые 2 минуты
- **Поиск людей** по `@юзернейму` или имени, ссылки на профиль вида `https://ваш-домен/@username`
- **Личные чаты**, **группы** (создание, добавление/удаление участников, смена названия и аватарки), **Избранное**
- Сообщения в реальном времени: **«печатает…»**, **онлайн / был(а) недавно**, **✓ / ✓✓ прочитано**, счётчики непрочитанных
- **Анимация отправки и получения** сообщений, клавиатура на телефоне не закрывается после отправки
- **Реферальная программа**: ссылка `/?ref=юзернейм`; новичок получает Plus на месяц, пригласивший — +месяц к своей подписке (или Plus); бонус один раз и только для новых аккаунтов
- **Истории** на 24 часа: фото с подписью или текст на цветном фоне, кружки над списком чатов, полноэкранный просмотр (тап — дальше, удержание — пауза, свайп вниз — закрыть), ответы и реакции приходят в личку, автор видит, кто посмотрел
- **Голосовые сообщения** с волной громкости и автопроигрыванием следующего
- **Пересылка** сообщений, **закреплённые сообщения** и **закреплённые чаты** (до 5)
- **Поиск по чату**, переход к старым сообщениям
- **Блокировка пользователей** (не могут писать и звонить), список в настройках
- Жесты как в Telegram: **свайп влево — ответить**, **двойной тап — ❤️**
- **Ответ**, **редактирование** (в т.ч. стрелкой ↑), **удаление у всех**, копирование
- **Фото**: кнопка, вставка из буфера, перетаскивание. Перед отправкой фото сжимаются, из них **удаляются EXIF и геолокация**
- Аватарки, «о себе», крупные эмодзи, ссылки, разделители по дням, просмотрщик фото
- **Светлая / тёмная тема** + 6 цветов акцента, уведомления в браузере
- **Активные сеансы** — видно, где выполнен вход, можно завершить
- Адаптив: на ПК — две колонки, на телефоне — экраны со свайп-анимацией и кнопкой «назад»
- **Админка только для вас** (см. ниже)

## Безопасность

- Вход только через Google, токен проверяется на сервере (подпись, `audience`, подтверждённый email)
- Сессии: случайный 256-битный токен в cookie `__Host-sid` (`HttpOnly`, `Secure`, `SameSite=Lax`), в базе хранится только SHA-256 хеш
- Защита от CSRF (проверка `Origin`) и от перехвата WebSocket с чужих сайтов
- Строгий **CSP**, HSTS, `X-Frame-Options`, `nosniff`, отключённые camera/mic/geo
- Лимиты частоты запросов на вход, отправку, загрузку и поиск
- Загрузки: только изображения, тип определяется по содержимому файла, случайные имена, приватная раздача (фото из чата видят только его участники)
- Весь пользовательский текст выводится через `textContent` — XSS через сообщения невозможен
- systemd-сервис запускается от отдельного пользователя с жёсткой песочницей

### Админка — как она защищена

Админка открывается по адресу `/admin`, но **только если выполнены все условия**:

1. Вы вошли через Google с email из `ADMIN_EMAILS`.
2. (Необязательно) ваш IP есть в `ADMIN_IPS`.
3. Вы ввели **6-значный код из приложения-аутентификатора** (Google Authenticator, Яндекс Ключ, Aegis…). Код одноразовый — повторно его использовать нельзя; попыток не больше 5 за 15 минут.
4. Разблокировка действует 15 минут и только на этом устройстве.

Всем остальным сервер отвечает `404` — снаружи не видно даже, что админка существует.
Если `ADMIN_EMAILS` или `ADMIN_TOTP_SECRET` не заданы — админка выключена полностью.
Все входы, неудачные коды, попытки доступа и действия админа пишутся в **журнал безопасности**.

В админке (разделы слева, на телефоне — вкладки сверху; быстрый поиск по **Ctrl+K**):

- **Обзор** — пользователи, DAU/WAU/MAU, графики сообщений, регистраций и активности за 30 дней, тепловая карта «когда пишут», самые активные чаты и люди.
- **Пульс** — онлайн, сообщения в минуту, нагрузка CPU и памяти, звонки и лента событий в реальном времени.
- **Жалобы** — пользователи жалуются на сообщения, профили, каналы и сообщества; одной кнопкой: удалить, удалить + запрет писать, удалить + бан, предупредить или отклонить.
- **Пользователи** — досье на каждого: статистика, активность, устройства, IP, журнал; временный бан с причиной (человек видит её при входе), запрет писать на время, удаление всех его сообщений, сообщение от Limochat, лимоны, подписка, галочка.
- **Каналы** и **Сообщества** — верификация и удаление.
- **Рассылка** — по аудиториям (все, подписчики, активные, «уснувшие», новички) с предпросмотром, и **баннер** над списком чатов у всех.
- **Платформа** — закрыть регистрацию, режим техработ, выключить истории, сообщества, ботов, капсулы с колесом; **стоп-слова** (заменяются звёздочками).
- **Безопасность** — устройства онлайн, баны по IP. **Сервер** — память, диск, база, обновление, **резервная копия базы одним файлом**. **Журнал** — поиск, фильтры, выгрузка в CSV.

Админ с входом по паролю (без Google): впишите его юзернейм в `deploy/admin-usernames.txt` — автообновление само добавит его в `ADMIN_USERNAMES`.
Читать чужую переписку админка не умеет — так задумано.

## Установка на сервер (Ubuntu 22.04 / 24.04, в т.ч. в РФ)

Нужно: VPS с публичным IP и домен (или поддомен), A-запись которого указывает на сервер.

### 1. Google Client ID

1. Откройте <https://console.cloud.google.com/> → создайте проект.
2. **APIs & Services → OAuth consent screen**: тип *External*, заполните название и email, опубликуйте (*Publish app*).
3. **APIs & Services → Credentials → Create credentials → OAuth client ID**:
   - Application type: **Web application**
   - Authorized JavaScript origins: `https://ваш-домен` (для локальной разработки можно добавить `http://localhost:3000`)
   - Redirect URI не нужен.
4. Скопируйте **Client ID** (вида `123…-abc.apps.googleusercontent.com`).

### 2. Установка одной командой

```bash
git clone <этот-репозиторий> limoninior && cd limoninior
sudo bash deploy/install.sh chat.ваш-домен.ru ваш@gmail.com
```

Скрипт поставит Node.js 22 и Caddy (автоматический HTTPS от Let's Encrypt), создаст системного пользователя, сервис systemd, настроит файрвол и **один раз покажет ключ для админки** — сразу добавьте его в приложение-аутентификатор.

Затем впишите Client ID и перезапустите:

```bash
sudo nano /opt/limoninior/.env        # GOOGLE_CLIENT_ID=...
sudo systemctl restart limoninior
```

Готово — откройте `https://chat.ваш-домен.ru`.

**Обновление:** происходит само — таймер `limoninior-update.timer` раз в 2 минуты проверяет GitHub и, если есть новая версия, переустанавливает её (данные и `.env` не трогаются). Вручную: кнопка «Обновить сейчас» в админке или `sudo bash deploy/install.sh`. Лог: `/var/log/limoninior-update.log`.

**Логи:** `journalctl -u limoninior -f`

**Бэкап:** всё хранится в `/opt/limoninior/data` (база SQLite + фото):

```bash
sudo apt install sqlite3
sudo sqlite3 /opt/limoninior/data/limoninior.db ".backup /root/limoninior-$(date +%F).db"
sudo tar czf /root/limoninior-media-$(date +%F).tgz -C /opt/limoninior/data media
```

### Вариант через Docker

```bash
cp .env.example .env && nano .env              # заполните APP_ORIGIN, GOOGLE_CLIENT_ID, ADMIN_*
npm run admin:totp -- ваш@gmail.com            # или: docker compose run --rm app node scripts/admin-totp.js
sed -i 's/chat.example.ru/chat.ваш-домен.ru/' deploy/Caddyfile.docker
mkdir -p data && sudo chown 1000:1000 data
docker compose up -d --build
```

> Если Docker Hub недоступен с вашего сервера, используйте установку через `install.sh` — она не зависит от Docker.

## Установка «как приложение»

- **ПК (Chrome / Edge / Яндекс Браузер):** значок установки в адресной строке или «Меню → Установить Limochat». Также пункт «Установить приложение» в боковом меню мессенджера.
- **Android (Chrome):** «⋮ → Установить приложение / Добавить на главный экран».
- **iPhone / iPad (Safari):** «Поделиться → На экран Домой».

## Локальная разработка

```bash
npm install
npm run dev          # http://localhost:3000, включён вход без Google (DEV_LOGIN=1)
```

Dev-вход работает **только** когда `NODE_ENV` не `production` и `DEV_LOGIN=1`.

## Про название

Мессенджер называется **Limochat** (раньше — Limoninior). Внутренние имена на сервере не менялись, чтобы обновление прошло без переустановки: папка `/opt/limoninior`, служба `limoninior`, файл базы `limoninior.db`.

## Стек

Node.js 22 (встроенный `node:sqlite`), Express 5, Socket.IO, google-auth-library, helmet.
Фронтенд — чистый JS без сборки, PWA с service worker.

```
server/   index.js (HTTP, CSP), api.js (REST), realtime.js (Socket.IO), auth.js (Google, сессии, CSRF),
          admin.js (админка + TOTP), media.js (загрузки), db.js (схема SQLite)
public/   index.html, js/app.js (мессенджер), js/admin.js, css/, sw.js, manifest, icons/
deploy/   install.sh, limoninior.service, Caddyfile
```
