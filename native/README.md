# Limochat — Android и Windows

Оба приложения открывают `https://81-90-31-167.sslip.io/` в отдельном окне и используют существующие аккаунты, чаты и настройки. Сервер должен быть доступен. Обновления интерфейса приходят с сайта; изменения нативной оболочки требуют новой установки.

## Скачать сборки

В GitHub откройте **Actions → Build APK and EXE → успешный запуск → Artifacts**.
- `Limochat-Android-APK`: ZIP с `Limochat-Android-test.apk`, Android 10+.
- `Limochat-Windows-EXE`: ZIP с установщиком `Limochat-Setup-1.0.0-x64.exe`, Windows 10/11 x64.

APK — тестовый, подписан стандартным debug-ключом сборочной машины. Это отдельное приложение `io.limochat.app.preview`, поэтому оно не заменяет старые неизвестные APK. Для обновляемых production-сборок нужен собственный постоянный закрытый ключ; его нельзя публиковать в репозитории. Windows-сборка без подписи издателя: Windows может показать предупреждение о неизвестном издателе.

## Что поддерживается

- Сохранение входа между запусками.
- Android: выбор файлов, скачивание в «Загрузки», системные запросы камеры, микрофона и геолокации, полноэкранное видео, кнопка «Назад», экран повтора при сетевой ошибке.
- Windows: отдельное окно, сохранение размера, масштабирование, камера/микрофон по запросу, выбор экрана для демонстрации.
- Внешние ссылки открываются в браузере; сайт не получает доступ к Node.js и файловой системе.

Это онлайн-клиенты, а не автономные серверы. APK не реализует FCM и фоновую доставку push, а звонки в фоне Android не поддерживаются отдельной foreground-службой. Закрытое приложение не гарантирует уведомления или входящий звонок. Это нужно отдельно проверить на настоящих устройствах и реализовать до production-релиза. Вход по логину/паролю поддерживается; Google OAuth внутри WebView может потребовать перехода во внешний браузер.

## Сборка

Android: JDK 17, Gradle 8.9, Android SDK 35, затем `cd native/android && gradle :app:assembleDebug`. Иконка копируется из `public/icons/icon-192.png` задачей Gradle.

Windows: Node.js 22, `cd native/desktop && npm install && npm run dist`. Создайте `native/desktop/icon.ico` из PNG перед сборкой (команда есть в workflow). Версии Electron и electron-builder закреплены в package.json. CI проверяет создание изолированного окна перед упаковкой.

Документация: [Android Gradle 8.7](https://developer.android.com/build/releases/agp-8-7-0-release-notes), [безопасность Electron](https://www.electronjs.org/docs/latest/tutorial/security).
