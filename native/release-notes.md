Limochat 1.1: Android browser-backed client and Windows tray notifications.

Android: needs an updated TWA-compatible browser (Chrome recommended). Enable Push notifications in Limochat and allow them in Android. This test package is separate from the earlier WebView preview. The APK signing certificate is published on the project's website for origin verification.

Windows x64: closing the window leaves the application in the tray. Enable notifications in Limochat settings. Full exit from the tray stops delivery. The installer has no publisher code-signing certificate.

These are test builds. Device notification delivery and active background calls still need testing on physical devices. No signing private keys are included.
