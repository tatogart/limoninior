# Limochat Liquid Glass — beta draft

Статус: **закрытая бета, готова к публикации по указанию пользователя от 26.11.2026**. Ветка: `draft/liquid-glass-beta-20261125`.

## Посмотреть локально

Из корня этой ветки:

```sh
npm ci --ignore-scripts --no-audit --no-fund
node scripts/preview-beta.mjs
```

Откройте `http://127.0.0.1:3195/beta`. Скрипт напечатает временный тестовый код. Создайте **локальный тестовый аккаунт**, вернитесь в бету и введите этот код. Скрипт использует отдельную временную базу: существующие чаты, пользователи и настройки сервера не меняются. После Ctrl+C тестовая база удаляется. Для другого порта: `node scripts/preview-beta.mjs 3196`.

Тестовый код создаётся только локальным скриптом разработчика. В обычной установленной версии коды создаются через защищённую админку.

## Готово в этом черновике

- Новый отдельный клиент `/beta`: светлые и тёмные стеклянные поверхности, адаптивная панель чатов, боковая личная панель; fallback при отсутствии backdrop-filter и учёт reduced-motion.
- Серверный доступ по кодам: случайные коды, хранение только хеша, срок 1–30 дней, 1–100 активаций, привязка к аккаунту на всех устройствах, отзыв администратором. Закрытые HTML/JS/CSS находятся вне public, прямые обращения к ним не дают доступ без сеанса и приглашения.
- Админка → «Закрытая бета»: создание и отзыв кодов, счётчик активаций, отзывы тестировщиков. Секретный код показывается только при создании.
- Настоящие чаты: фильтры, поиск по списку и Ctrl+K, история с загрузкой старых сообщений, отправка текста, файлов и изображений, просмотр стикеров, обновление чатов каждые 8 секунд.
- Режим фокуса, быстрые ответы, вставка эмодзи, локальные заметки к чату, компактный вид, четыре акцентных цвета и отдельная тема беты.
- Отзывы отправляются в админку. После истечения или отзыва приглашения API и ресурсы беты закрываются; основной клиент продолжает работать.

## Границы первой беты

При будущей установке на общем сервере бета использует те же чаты: отправленное сообщение видно в основном клиенте. Это явно указано при входе и в лаборатории. Только локальный предпросмотр из команды выше изолирован отдельной базой.

В бете пока нет самостоятельных интерфейсов звонков, управления группами, редактирования профиля, покупки подарков и сложных игровых карточек. Исполняемые вложения открываются через основной клиент с его проверками. Для этих действий есть ссылка на обычный Limochat; исходные возможности основного клиента остаются доступны. Заметки и настройки беты хранятся на устройстве отдельно по аккаунтам. Временные папки и тестовые аккаунты не следует использовать для постоянных данных.

Коды не являются заменой входу в аккаунт и ограничениям основного API. Админка сохраняет свои текущие проверки роли и TOTP. Service Worker не кэширует `/beta` и `/api/beta`.

## Проверки и дальнейший просмотр

```sh
node --test tests/beta-access.test.js tests/beta-http.test.js
npm test
find server public/js beta scripts tests -type f \( -name '*.js' -o -name '*.mjs' \) -exec node --check {} \;
```

Автоматически проверяются доступ к HTML/ресурсам, запрет неавторизованных запросов, хеши кодов, лимиты активаций, привязка к аккаунту, срок действия, отзыв, доступ админа, feedback и отправка настоящего сообщения через прокси. Отдельно проверяется сохранение доступа к обычным чатам после отзыва беты.

Перед публикацией нужен визуальный просмотр на ПК и телефоне: клавиатура, длинные сообщения, производительность размытия, фокус и контраст обеих тем. Локальный headless Chromium в текущем окружении недоступен, поэтому визуальная приёмка не заявляется выполненной. Публикация разрешена пользователем 26.11.2026. Возврат через «Основной сервер» не удаляет доступ к бете.
